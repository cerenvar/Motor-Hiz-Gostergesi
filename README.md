##  Özellikler
* **Çoklu Derleyici Desteği:** Proje; Keil µVision, IAR Embedded Workbench ve GCC (Makefile) üzerinden derlenebilir.
* **Hız Hesaplama:** Sensörden gelen sinyaller işlenerek motor hızı (RPM/Hız) hesaplanır.
* **Görselleştirme:** Hesaplanan veriler bağlı bulunan ekran modülüne aktarılır.

##  Klasör Yapısı
* **/Keil:** Keil IDE kullanıcıları için proje dosyaları.
* **/IAR:** IAR Embedded Workbench kullanıcıları için proje dosyaları.
* **/GCC:** Komut satırı veya açık kaynak araçlarla derleme yapmak için Makefile içeriği.
* **main.c:** Ana algoritmanın ve motor hız hesaplama mantığının bulunduğu dosya.
